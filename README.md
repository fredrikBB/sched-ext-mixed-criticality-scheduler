# EDF-VD scheduler for sched_ext

Fork of [`scx-c-examples`](https://github.com/sched-ext/scx-c-examples) adding an Earliest Deadline First with Virtual Deadlines (EDF-VD) scheduler for mixed-criticality systems.

This repository is related to the master's thesis *Mixed Criticality on Linux MPSoC Platforms*, submitted to the Norwegian University of Science and Technology (NTNU) in 2026.

**Thesis:** https://hdl.handle.net/11250/5581871
